# Синхронизация прогресса с Cloudflare D1

WHITE ROOM читает локальную SQLite и отправляет в приватную базу D1 изменения в учебном прогрессе и журналах активности. В облачную копию входят фокус-сессии, карточки и их расписание, ответы на вопросы, результаты задач, заголовки окон, домены, заголовки страниц и сохранённые выдержки.

Облачная схема хранит состояние задач и итоги попыток. Условия и код заданий, файлы, ключи ответов, бинарники и флаги хранятся только локально. Токен доступа передаётся фоновому процессу через зашифрованные credentials systemd.

Первый запуск копирует существующие записи. Последующие запуски сравнивают контрольные суммы и отправляют новые или изменённые записи. Сверка в D1 предшествует записи отметки об успешной синхронизации. Облачная копия сохраняет уже загруженные записи при локальной очистке.

## Проверка

```bash
python3 -B scripts/progress_sync.py preview
systemctl --user list-timers whiteroom-progress-sync.timer
journalctl --user -u whiteroom-progress-sync.service -n 10 --no-pager
```

`preview` печатает только количество записей по категориям. Таймер запускает копирование раз в 15 минут, пока работает пользовательский systemd. При следующем запуске systemd таймер подхватывает пропущенную синхронизацию. Немедленный запуск доступен через `systemctl --user start whiteroom-progress-sync.service`.

В консоли Cloudflare число сохранённых записей можно посмотреть без самих журналов.

```sql
SELECT collection, COUNT(*) FROM whiteroom_progress GROUP BY collection;
```

Скрипт выполняет одностороннее копирование из SQLite в D1. [API Cloudflare D1](https://developers.cloudflare.com/api/resources/d1/subresources/database/methods/query/)
