# Claude Code — интерфейс ИИ-тьютора

Рабочая папка WHITE ROOM — `/home/usual/Work/whiteroommode`. Твои файлы для записи — `whiteroom-app/ui/`. Сохрани актуальный фон, сценарий входа в комнату и настройки движения. Codex отвечает за Rust, команды Tauri, разрешения и проверки политики тьютора.

## Раздел и окно в сессии

- Вне фокус-сессии добавь обычный раздел «ИИ-тьютор» в основную навигацию. Здесь можно выбрать понятие или задать вопрос.
- В активной фокус-сессии открывай компактный диалог из белой комнаты. Диалог показывает понятие, предложенное для текущего режима, и позволяет выбрать другое из списка. Для формулировок доступны определение и нейтральный пример. Правило для этого режима — объяснение теории. Свободный текст задания и историю сессии интерфейс в запрос не добавляет.
- Форму делай доступной с клавиатуры. При открытии ставь фокус в диалог. Esc и кнопка закрытия возвращают фокус на кнопку вызова. Таймер сессии продолжает идти. При завершении или смене сессии закрой окно, отмени предпросмотр и сбрось черновик.
- Для облачного запроса покажи отправку в два шага. Сначала точный JSON и оценка токенов, затем явные кнопки «Отправить» и «Отмена». Размещай JSON обычным текстом, сохрани переносы и прокрутку. Локальное объяснение можно получить сразу. Во время обработки блокируй повторное нажатие. Текст ответа тоже вставляй как текст.
- Тьютор показан как чат. Подтверждённые вопросы и ответы хранятся в таблице `tutor_message` до конца локальных суток (D13); `tutor_context` возвращает их в поле `messages: [{role: "user"|"tutor", text}]` для текущей сессии или страницы вне сессии.

## Контракт Tauri

Используй действующие `read()` для возвращаемых строк JSON и `invoke()` для `void`. Имена параметров и полей ниже в camelCase.

| Вызов | Параметры | Результат |
| --- | --- | --- |
| `tutor_context` | Нет | `{sessionId: number|null, suggestedConceptId: string|null, concepts: [{id: string, title: string}]}` |
| `tutor_prepare` | `{sessionId, question, conceptId}` | `{previewId: string, sessionId: number|null, local: boolean, requestJson: string, estimatedTokens: number}` |
| `tutor_send` | `{previewId}` | `{sessionId: number|null, answer: string}` |
| `tutor_cancel` | `{previewId}` | `void` |

Для необязательных полей `question` и `conceptId` передавай `null`, когда они пусты. В сессии используй выбранный `conceptId` и `question: null` для определения, строку `Пример: <название понятия>` для примера или `Сравни: <название понятия>` для сравнения. При `local: true` вызывай `tutor_send` сразу. Результат берётся из встроенного каталога, а `requestJson` пустой. При `local: false` вызывай `tutor_send` после явного подтверждения. После изменения вопроса или понятия подготовь новый черновик. Срок его действия — 120 секунд. Показывай ошибку устаревшего черновика с возможностью подготовить его заново. Перед выводом ответа сравни его `sessionId` с открытым представлением.

## Приёмка

С временной БД и заглушкой IPC проверь раздел вне сессии, открытие мини-чата во время сессии и актуальное рекомендуемое понятие. Проверь отмену, повторное нажатие, смену сессии между предпросмотром и подтверждением, закрытие по Esc и возврат фокуса. На 360 и 900 px JSON прокручивается, а кнопки подтверждения доступны. При возможности повтори сценарий в WebKitGTK. Для визуальной проверки используй ответ-заглушку.
