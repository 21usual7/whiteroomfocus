## Что это

Десктоп-приложение для самообучения: Linux, Hyprland, Chromium. Пользователь учится как обычно (сейчас — реверс и pwn x86-64, позже математика). WHITE ROOM записывает, чем он занимался. После сессии ИИ (Claude API) задаёт 2–3 вопроса и генерирует практические задачи по теме. Повторения идут по FSRS. Решения в продукте опираются на исследования из docs/research: retrieval practice, интервальные повторения, лестница подсказок, полное решение только после попытки.

## Как работать с пользователем

- Общайся по-русски. Интерфейс и тексты — тоже по-русски.
- Код минимальный: без лишних абстракций, файлов и опций. Комментарии — только «почему». Сохраняй существующий стиль и структуру. Ошибки — `Res<T> = Result<T, String>`.
- Платного ИИ пока нет: API-ключа нет, кредиты не куплены. Код для Claude API пиши и проверяй на заготовленных ответах. Реальные запросы не отправляй.
- Перед действиями вне проекта спрашивай. Сюда относятся: конфиг Chromium пользователя (`whiteroom browser-setup`), установка пакетов, sudo, push.
- Окна на рабочем столе пользователя открывай только ненадолго и только чтобы сделать скриншот (grim + `hyprctl clients -j` для геометрии), потом закрывай.
- Отчитывайся честно: что проверено запуском, а что нет.

## Окружение

- Rust через mise. Команды: `mise exec -- cargo ...` из корня. Корень — Cargo workspace, общий `target/`, `[profile.dev] debug = "line-tables-only"`.
- Диск почти полон: занято 96%, свободно ~3.7 ГБ. Не создавай копий кеша cargo. Большие артефакты удаляй.
- Есть: bubblewrap 0.13, systemd 262 (`--user`), gcc, gdb, python 3.14 + sympy + pwntools, Chromium 155, node 26, Hyprland 0.56.

## Что сделано (всё покрыто тестами, 24 теста в whiteroom-core)

- `whiteroom-core/src/lib.rs`:
  - SQLite;
  - модуль-пилот (`modules/re-x86-64.toml`, ключи ответов проверены запуском через gcc);
  - сессии повторений: FSRS 7, прогноз и калибровка;
  - трекер активного окна Hyprland (`track`, `log`);
  - `review` (вопросы от Claude по активности, показ и подтверждение перед отправкой);
  - страницы от расширения (native messaging, проверка ввода);
  - учебные сессии `start`/`stop` (трекер как временный сервис systemd `whiteroom-track`);
  - блок-лист сайтов.
- `src/sandbox.rs`: раннер по контракту 8.1 (systemd-run --scope + bwrap, без сети, fd ≥3 закрыты через close_range, лимиты на всё дерево, папка задания в tmpfs). Приёмочные тесты — `tests/sandbox.rs`. Не ослабляй их и не добавляй обходного пути.
- `src/challenge.rs`: задачи pwn и math. Любая задача перед выдачей проверяется в песочнице эталонным решением: эксплойт pwntools должен получить флаг, verify — напечатать ok. Есть подсказки по 4 уровням (полное решение — только после попытки), `pwn run/gdb` в песочнице, сдача флага, символьная проверка ответа через SymPy в песочнице, генерация агентом (`ai_request`/`from_response` + `practice` в CLI, до 3 попыток с текстом ошибки). Образцы — `challenges/examples/*.json`.
- `src/idle.rs`: простой через ext-idle-notify v2 (`get_input_idle_notification`: игнорирует idle inhibitors).
- `extension/` (Chromium MV3): домен и заголовок вкладки, текст только с сайтов, отмеченных «Учебный сайт» (optional host permissions), блокировка через declarativeNetRequest во время сессии. Проверено в изолированном headless-профиле.
- `whiteroom-app/` (Tauri 2, статический фронтенд без npm): вкладки «Сессия» (старт/стоп, таймер, сводка), «Повторения» (прогноз, вопросы, подсказка, работа над ошибками), «Практика» (условие, подсказки, сдача, файлы pwn и команды), «Сайты». 15 команд, в capabilities разрешены только они. Окно проверено на Hyprland, скриншоты всех вкладок в 900 px — без наложений. Мелкий долг: в `src/main.rs` ответы сериализуются в JSON через `tauri::ipc`, а не через serde_json (`json()`); можно упростить, добавив `serde_json` в зависимости.

## С чего начать

1. Проверь состояние: `mise exec -- cargo build --workspace` и `mise exec -- cargo test -p whiteroom-core`. Должно быть 24 теста, все зелёные. Тесты песочницы запускают настоящие bwrap/systemd-run и занимают ~6 с.
2. Код окна должен оставаться тонкой обёрткой над ядром. В capabilities Tauri — только свои команды, без плагинов fs/shell/http, CSP строгая.
