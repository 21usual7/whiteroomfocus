# Claude Code — получить историю WHITE ROOM по SSH

Локальная история теперь доступна (master, 2ef31a0). Bundle нужен только при отсутствии нужной истории в рабочей копии. На рабочем компьютере проверь доступ командой `git ls-remote --symref git@github.com:21usual7/whiteroomfocus.git HEAD`. Используй настроенный SSH-клиент с обычной проверкой подлинности сервера. Если GitHub возвращает ветки, клонируй репозиторий в новую временную папку, выполни в клоне `git bundle create /home/usual/Work/whiteroommode/whiteroom-history.bundle --all` и проверь файл через `git bundle verify`. Если файл уже существует, сначала проверь его. Сообщи путь, ветку и HEAD. Если удалённый репозиторий пуст, сообщи это отдельно. При ошибке укажи этап и текст ошибки. Задача ограничена чтением истории с GitHub и передачей её локально. Ключ остаётся в SSH-клиенте.
