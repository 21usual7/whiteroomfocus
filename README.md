# WHITE ROOM

Учишься как обычно. WHITE ROOM записывает, чем ты занимался. В конце ИИ задаёт вопросы и составляет задачи по этой теме. Повторения приходят по расписанию FSRS.

Исследование и спецификация: `docs/research/`.

## Сборка

```
mise exec -- cargo build --release      # CLI: target/release/whiteroom, окно: target/release/whiteroom-app
mise exec -- cargo test -p whiteroom-core
```

Нужны: Hyprland, Chromium, `bubblewrap`, `systemd --user`, `gcc`, `python` с `sympy` и `pwntools`.

## Фокус-сессии по кибербезопасности

Из корня проекта запусти окно:

```
mise exec -- cargo build --workspace
./target/debug/whiteroom-app
```

Во вкладке «Фокус» выбери режим и направление. Перед стартом можно отдельно разрешить запись окон и вкладок. В каждой новой сессии оба источника выключены. Во время занятия источник можно отключить, таймер продолжит работать. Есть изучение, врайтап, баг-баунти, хантинг угроз, CTF и исследование. Например, для хантинга можно выбрать «Анализ журналов» и уточнить тему занятия. Если тему оставить пустой, заголовком сессии станет направление. Нажми «Начать сессию», а в конце — «Закончить». После повторного открытия окна таймер продолжит отсчёт от сохранённого времени старта. Последние пять завершённых фокус-сессий видны под формой. Выбор режима и история работают локально без ключа API.

## Один вечер

```
whiteroom block add youtube.com     # один раз: что блокировать во время сессии
whiteroom start --windows --browser сети   # разрешить оба источника для этого занятия
…учишься…
whiteroom stop                      # сводка сессии
whiteroom review                    # ИИ: 2–3 вопроса по сессии → в повторения
whiteroom practice pwn              # ИИ: челлендж по теме, проверенный в песочнице
whiteroom session                   # в следующие дни: повторения
```

Перед каждым запросом к Claude API, включая повторные попытки, CLI показывает JSON и ждёт `y`. По умолчанию в разбор входят записи последней сессии с её идентификатором. Для старых записей без привязки можно явно выбрать период командой `whiteroom review 4` (последние четыре часа). Ключ задаётся так: `export ANTHROPIC_API_KEY=…`.

## Практика

```
whiteroom challenges                # список
whiteroom show 3                    # условие; файлы для Ghidra в ~/whiteroom/challenges/3
whiteroom hint 3                    # идея → метод → первый шаг → решение (решение — после попытки)
whiteroom pwn run 3                 # бинарь в песочнице; pwntools: process(['whiteroom','pwn','run','3'])
whiteroom pwn gdb 3                 # gdb в песочнице
whiteroom solve 3 'WR{…}'           # флаг; для математики — выражение: whiteroom solve 4 'exp(1/e)'
```

Каждую задачу перед выдачей проверяет эталонное решение в песочнице: эксплойт должен получить флаг, проверочный код — подтвердить ответ. Задача, которая не прошла проверку, не выдаётся. Бинари написаны ИИ, поэтому напрямую их не запускай.

Без ключа можно добавить задачу из файла: `whiteroom challenge add challenges/examples/pwn-ret2win.json`. Формат задачи описан в `whiteroom-core/src/challenge.rs`, примеры лежат в `challenges/examples/`.

## Браузер

```
whiteroom browser-setup             # связать с расширением
```

Дальше: `chromium://extensions` → «Режим разработчика» → «Загрузить распакованное» → `extension/`. Когда в активной сессии разрешены вкладки, расширение записывает домен и заголовок. Текст страниц оно сохраняет только с сайтов, которые ты отметил кнопкой «Учебный сайт». Всё хранится локально.

## Данные

База лежит в `~/.local/share/whiteroom/whiteroom.db`, можно указать другую через `$WHITEROOM_DB`. Экспорт всех данных: `whiteroom export`.
